# rice-mobile

Launcher Android personal. Elegir un rice completo (`monochrome`, `arctic_glass`, `ember_forge`, `ivory_paper`, `violet_night`) transforma composición, tipografía y motion, compartiendo catálogo, acciones y preferencias.

V1 muestra las apps del perfil actual (no todas las apps de todos los perfiles).

El contrato técnico vinculante de V1 vive en [`docs/V1_EXECUTION_CONTRACT.md`](docs/V1_EXECUTION_CONTRACT.md). Toda decisión de arquitectura, toolchain y sprint se rige por ese documento.

## Estado

Bootstrap documental de `main`. El trabajo funcional de cada sprint se desarrolla en su branch (`feat/launcher-spine`, `feat/rice-engine`, `feat/v1-rices`, `release/v1`) y se integra mediante PR.
